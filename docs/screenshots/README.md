# Screenshots

Captured from a local run of the full app with fictional demo data. The demo
data was created through the real API by a seeding script, and the images
were captured with headless Chrome over the DevTools protocol. Both scripts
live in the private repo.

| File | What it shows |
|---|---|
| `browse.png` / `browse-full.png` | Public browse page: featured auctions and all live auctions |
| `proxy-auction.png` | Proxy auction mid bidding war, signed in as the leading bidder |
| `ending-soon.png` | Proxy auction close to its end (anti-sniping extension window) |
| `dutch-auction.png` | Dutch auction: price, floor, drop rate and interval |
| `vickrey-auction.png` | Vickrey sealed-bid form; amounts stay hidden until close |
| `candle-auction.png` | Candle auction with a hidden end time |
| `my-bids.png` | A bidder's bids across auctions |
| `create-auction.png` | Seller's create-auction form |
| `admin-panel.png` | Admin operations dashboard with an auction awaiting review |
| `mobile-browse.png` / `mobile-auction.png` | 390 px wide mobile layout |
